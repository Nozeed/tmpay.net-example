# TMPAY Payment System

ระบบเติมเงินบัตร TrueMoney และ Razer Gold Pin ผ่าน TMPAY.net

## ไฟล์ประกอบระบบ

### ไฟล์หลัก
- `tmpay-api.php` - ฟังก์ชันส่งค่าไปยัง TMPAY API
- `tmpay-callback.php` - รับค่า callback จาก TMPAY เมื่อเติมเงินสำเร็จ/ไม่สำเร็จ
- `db.php` - การเชื่อมต่อฐานข้อมูลและการตั้งค่า TMPAY
- `db.sql` - โครงสร้างฐานข้อมูล

### ไฟล์ทดสอบ
- `index.php` - หน้าเติมเงิน (กรอกเลขบัตร 14 หลัก)
- `check-credit.php` - ดูเครดิตและประวัติการเติมเงิน

## การติดตั้ง

### 1. สร้างฐานข้อมูล
```bash
mysql -u root -p < db.sql
```

หรือนำเข้าผ่าน phpMyAdmin ไฟล์ `db.sql`

### 2. แก้ไขการตั้งค่าใน `db.php`
```php
$db_host = 'localhost';      // แก้ไขตามเซิร์ฟเวอร์ของคุณ
$db_name = 'tmpay';          // ชื่อฐานข้อมูล
$db_user = 'root';           // ชื่อผู้ใช้ฐานข้อมูล
$db_pass = '';               // รหัสผ่านฐานข้อมูล

$merchant_id = 'YOUR_MERCHANT_ID';  // แก้ไขเป็น Merchant ID จาก TMPAY
$callback_url = 'http://localhost/tmpay-callback.php';  // แก้ไข URL ให้ตรงกับเซิร์ฟเวอร์ของคุณ
```

### การทดสอบระบบด้วย Merchant ID ทดสอบ
สามารถทดสอบระบบโดยไม่ต้องใช้บัตรจริง โดยตั้งค่า `$merchant_id = 'TEST';` ใน `db.php`

**เลขบัตรทดสอบและจำนวนเงิน:**
- 55555555555551 = 50 บาท
- 55555555555552 = 90 บาท
- 55555555555553 = 150 บาท
- 55555555555554 = 300 บาท
- 55555555555555 = 500 บาท
- 55555555555556 = 1000 บาท

### 3. ทดสอบระบบ
เปิดเบราว์เซอร์ไปที่ `http://localhost/check-credit.php` ก่อนเพื่อสร้างฐานข้อมูล test
จากนั้นทดสอบเติมเงิน `http://localhost/index.php`

## โครงสร้างฐานข้อมูล

### ตาราง users
- `id` - ID ผู้ใช้ (ใช้เป็น '1' สำหรับการทดสอบ)
- `username` - ชื่อผู้ใช้
- `credit` - เครดิตคงเหลือ
- `created_at` - วันที่สร้าง

### ตาราง refill_log
- `id` - ID รายการ
- `user_id` - ID ผู้ใช้
- `card_code` - รหัสบัตร 14 หลัก
- `transaction_id` - ID ธุรกรรมจาก TMPAY
- `amount` - จำนวนเงินที่เติม
- `status` - สถานะ (0=รอตรวจสอบ, 1=สำเร็จ, 2=ไม่สำเร็จ, 3=รอตรวจสอบ)
- `pay_type` - ช่องทาง (truemoney หรือ razer_gold_pin)
- `created_at` - วันที่สร้าง
- `updated_at` - วันที่อัปเดต

## การทำงานของระบบ

### ขั้นตอนเติมเงิน
1. ผู้ใช้กรอกเลขบัตร 14 หลักและเลือกช่องทางใน `index.php`
2. ระบบตรวจสอบว่าบัตรถูกใช้ไปแล้วหรือไม่
3. ส่งข้อมูลไปยัง TMPAY API ผ่าน `tmpay-api.php`
4. TMPAY ตรวจสอบบัตรและส่งค่ากลับ
5. บันทึกข้อมูลลงฐานข้อมูลด้วยสถานะ "รอตรวจสอบ"
6. TMPAY เรียก callback ไปยัง `tmpay-callback.php` เมื่อตรวจสอบเสร็จสิ้น
7. ระบบอัปเดตสถานะและเพิ่มเครดิตให้ผู้ใช้

### สถานะรายการ
- **0** - รอตรวจสอบ (ส่งไป TMPAY แล้ว รอ callback)
- **1** - สำเร็จ (เติมเงินเรียบร้อย)
- **2** - ไม่สำเร็จ (บัตรไม่ถูกต้องหรือถูกใช้ไปแล้ว)
- **3** - รอตรวจสอบ (สำรอง)

## ความปลอดภัย

- ใช้ PDO Prepared Statements ป้องกัน SQL Injection
- ตรวจสอบรูปแบบเลขบัตร 14 หลัก
- ตรวจสอบบัตรซ้ำก่อนส่งไป TMPAY
- ปกป้อง callback จากการเรียกซ้ำ

## หมายเหตุ

- ระบบนี้เป็นตัวอย่างเพื่อการทดสอบเท่านั้น
- ต้องได้รับ Merchant ID จาก TMPAY.net ก่อนใช้งานจริง
- Callback URL ต้องเข้าถึงได้จากภายนอก (ไม่ใช่ localhost) เมื่อใช้งานจริง
- ควรเพิ่มการตรวจสอบความถูกต้องของ callback เพิ่มเติมในการใช้งานจริง

## ช่องทางที่รองรับ
